# Study Check-In (working title)

A free, minimalistic study website where a funny animated character pops out from behind a door to check that you're still studying.

## Run it

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
npx serve .
```

Then open the address it prints (normally http://localhost:3000).

Don't open `index.html` by double-clicking it. The JavaScript is split into modules, which browsers only load from a web address, so the page would stay blank.

## How it's made

Plain HTML, CSS and JavaScript, with no framework and no AI-generated images. The door and the characters are drawn as SVG shapes, and their movements are CSS keyframe animations.
